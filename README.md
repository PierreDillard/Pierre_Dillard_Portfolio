# Portfolio Pierre Dillard

La V1 est un portfolio statique en français : ouvrir `index.html` directement ou lancer `python3 -m http.server 8000` depuis ce dossier. La [V2 React / Next.js](v2/README.md) contient les études de cas GPAC, le journal et un éditeur local pour modifier le portfolio sans toucher au code.

## Sources et visuels

- `assets/CV_Pierre_Dillard_2026.pdf` : CV fourni par Pierre.
- `assets/pierre.jpg` : portrait local fourni par Pierre.
- `assets/gpac-monitor-overview.png` et `assets/gpac-monitor-history.png` : captures réelles fournies par Pierre le 7 octobre 2026.
- Les cartes Agent Workflow Kit / EPR sont des compositions éditoriales, pas des captures produit.
- Direction visuelle inspirée de [My Design Portfolio 2019–2021](https://www.behance.net/gallery/134108419/My-Design-Portfolio-2019-2021) par Fengrui Wang : couverture dramatique, typographie monumentale et narration par projets. Aucun visuel Behance n'est reproduit.
